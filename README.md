## ⭐ Featured Project

### [EEPROM24CXX](https://github.com/AlenKrishna2012/EEPROM24CXX)

An Arduino library for **24Cxx and 24CMxx I²C EEPROM chips**.

**Highlights**
- 24Cxx / 24CMxx family support
- Byte, string, buffer and data access
- Erase, fill and compare utilities
- Write-protection support
- Arduino-style API
